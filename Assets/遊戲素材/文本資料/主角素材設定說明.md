# 主角素材設定說明（給團隊）

## 這是什麼

**想替換謬爾的動畫、音效、配音或特效，只要在 Unity 裡改幾個資料檔，完全不用碰程式。**

這套「素材設定檔」把主角每個動作要用的東西集中放在一起：播哪個動畫、發出什麼聲音、說什麼配音、出現什麼特效。美術、音效、企劃都可以直接動手，不需要等工程師。

這份說明只談「怎麼用」。看完你就能：

- 找到設定檔放在哪裡
- 替換某個動作的動畫
- 幫某個動作加音效、配音、特效
- 知道哪些地方不要碰

## 先認識三個東西

**一個總表、四本武器手冊、每本手冊裡的一頁頁動作。** 把它想成一套書：

| 名稱 | 白話比喻 | 數量 | 要改素材時 |
| --- | --- | --- | --- |
| 主角素材總表（PlayerProfile） | 目錄，列出四本手冊分別在哪 | 1 個 | 一般不用改 |
| 武器動作集（WeaponActions） | 一把武器的手冊，記錄這把武器所有動作的素材 | 4 個（鉛筆、水彩筆、畫刀、調色盤） | **主要在這裡改** |
| 動作 | 手冊裡的一頁，例如「輕攻擊」「受擊」 | 每把武器約 13 個 | 展開後填寫素材 |

每把武器的動作都獨立，不會互相影響。你想改「鉛筆輕攻擊的音效」，只要開「鉛筆」這本手冊，找到「輕攻擊」這一頁就好。

翻滾和死亡四把武器共用同一個動畫，所以另外放在總表裡的「共用動作」。

## 檔案在哪裡

**全部在 Unity 的 Project 視窗裡，資料夾路徑是 `Assets/遊戲素材/SO/主角/`。**

| 檔名 | 是什麼 |
| --- | --- |
| `WeaponActions_Pencil` | 鉛筆的手冊 |
| `WeaponActions_Brush` | 水彩筆的手冊 |
| `WeaponActions_PaintKnife` | 畫刀的手冊 |
| `WeaponActions_Palette` | 調色盤的手冊 |
| `PlayerProfile` | 總表（四本手冊的目錄，加上翻滾、死亡的共用動作） |

打開方式：

1. 在 Unity 下方的 **Project** 視窗，依序展開 `遊戲素材` → `SO` → `主角`。
2. 用滑鼠左鍵**單點**你要改的武器手冊（不用雙擊）。
3. 右邊的 **Inspector** 視窗就會顯示它的內容。

看不到 Inspector 視窗的話，到上方選單「Window → General → Inspector」打開。

## 一個動作裡的欄位

**點開一本武器手冊，會看到一頁頁動作；展開其中一頁，只有下面六項需要你填。**

動作標題會寫出「動作名稱（目前的動畫名 · 動畫長度）」，例如「輕攻擊（SoftAttack_pencil · 1.70s）」。動作依「跳躍下落 → 攻擊 → 連段 → 特殊技能 → 切換武器 → 受擊」分組排列。

| 欄位 | 填什麼 | 留空會怎樣 |
| --- | --- | --- |
| 動畫 Clip | 這個動作要播的動畫。換成別的動畫，動作時間會自動跟著新動畫的長度走 | 照原本的動畫播 |
| 音效 | 一份清單，可以放多個，每次動作發生時**隨機播其中一個**。拖進來的是「音效資料」（SoundEffectData），不是音檔 | 沒有聲音，不會出錯 |
| 音效時間點 | 音效在動畫哪個位置播，0 = 一開始就播，1 = 動畫結束時才播（見下方範例） | 0（一開始就播） |
| 配音 | 用法跟音效一樣，只是用來放角色的聲音 | 沒有配音 |
| 配音時間點 | 用法跟音效時間點一樣 | 0 |
| 特效 | 可以放多個特效，每個特效的設定見下表 | 沒有特效 |

**每個特效要填的資料：**

| 欄位（Inspector 上顯示的名稱） | 意思 |
| --- | --- |
| Prefab | 特效的 Prefab。**留空就不生成，不會出錯** |
| Bone Name | 特效要出現在哪個骨骼上（例如右手是 `DEF-hand_attach.R`）。留空 = 出現在角色腳底 |
| Position Offset | 跟骨骼的距離偏移（X 左右、Y 上下、Z 前後，單位公尺） |
| Rotation Offset | 旋轉角度偏移 |
| Normalized Time | 特效在動畫哪個位置出現，用法和音效時間點一樣（0 ~ 1） |
| Follow Bone | 勾選 = 特效出現後跟著骨骼一起動；不勾 = 留在原地 |
| Lifetime | 特效幾秒後自動消失，預設 3 秒。0 = 不自動消失 |

**時間點範例：** 鉛筆輕攻擊的動畫長 1.7 秒，揮出去的「咻」聲在第 0.5 秒。0.5 ÷ 1.7 ≈ 0.3，所以時間點填 0.3。之後換成別的動畫，長度不同也不用重算。

最下面還有一個收起來的「進階（程式用，一般不用改）」，**請不要展開修改**，從它的名字就知道是給程式對應用的。

## 常見操作

**換動畫、加音效、加配音、加特效，流程都一樣：先點開武器手冊 → 展開要改的動作 → 填欄位。** 下面分開講。

### 開始前（每次都一樣）

1. 在 Project 視窗單點要改的武器手冊（例如 `WeaponActions_Pencil`）。
2. 在右邊 Inspector 找到要改的動作，點標題前面的小箭頭展開。

### 替換動畫

1. 展開動作後，將新的動畫檔從 Project 視窗拖到「動畫 Clip」欄位。
2. 標題括號裡的動畫名和秒數會自動更新，表示已經換好了。
3. 動作時間會自動跟著新動畫的長度走，不用額外設定。

要求：這個動作原本要已經有動畫（標題不是「無動畫」）。顯示「無動畫」的動作，請先找工程師建立，見「注意事項」。

### 加音效或配音

1. 先建立「音效資料」：在 Project 視窗空白處按右鍵 → **Create → PilgrimOfSin → 音效 (Sound Effect)**。
2. 點這個新檔案，把音檔拖進「音檔變體」。放幾個都可以，每次會隨機播一個。
3. 回到武器手冊，展開動作，把這個音效資料拖進「音效」（配音則拖進「配音」）的清單。
4. 想同一個動作有多種音效可變化，清單右下角按 **+** 多加一格。
5. 需要對到動畫某個瞬間的話，填「音效時間點」（見前面的範例）。

### 加特效

1. 先準備好特效 Prefab（由美術建立）。
2. 展開動作的「特效」清單，按 **+** 新增一筆。
3. 把 Prefab 拖進「Prefab」。其他欄位先用預設即可，測試後再微調。
4. 特效位置不對時：修改 Position Offset；想改出現在其他骨骼，填 Bone Name（不確定骨骼名字時請問工程師）。

### 測試怎麼看效果

1. 按 Unity 上方的 **▶ 播放**鍵。
2. 用主角做出那個動作，聽、看是否符合。
3. 測完再按一次播放鍵停止。
4. **注意：在播放狀態下改的內容，停止後會消失。** 想保留的修改請先停止再改。

## 注意事項

**最重要的三件事：不要展開「進階」、沒有「原本的動畫」就不能換、換動畫會影響翻滾與受擊的時間。**

- **不要展開「進階」。** 裡面是程式對應動畫用的資料，改錯會讓這個動作完全失效。
- **標題顯示「無動畫」的動作，先找工程師。** 目前水彩筆、畫刀、調色盤的「切換武器」還沒有動畫連結，需要工程師先在動畫控制器建立好，再回來放動畫。
- **換動畫會改變翻滾和受擊的時間。** 翻滾和受擊硬直的時間跟著動畫長度走，換長的動畫會讓硬直變長，翻滾的無敵時間也變長，影響難度與手感，換之前請和企劃確認。
- **同一個原始動畫被多個動作共用時，換掉它會一起換。** 例如有兩個動作用同一個動畫，只換其中一個的話兩個都會變。
- **時間點只在動作有動畫時才有意義。** 沒有動畫的動作，音效、配音、特效都會一開始就出現。
- **動作被打斷時，還沒播的會取消。** 例如攻擊途中受傷，等待中的音效、特效就不會出來。
- **在播放狀態下改的內容，停止後會消失。** 請先停止再改。

**不在這裡的東西：**

| 想改 | 在哪裡 |
| --- | --- |
| 按鍵設定 | `Assets/遊戲素材/PlayerInputActions`，改前請先問工程師 |
| 武器模型、拿武器的角度 | 主角 Prefab 上的 PlayerWeaponVisual，請找工程師 |
| 傷害、血量、移動速度 | 主角 Prefab 的 PlayerController 與 PlayerCombat，請找工程師 |

**多人同時改的時候：** 同一本武器手冊如果兩個人同時改，提交到 git 時很可能衝突。請在群組說一聲「我要改鉛筆」，一次只有一個人動同一本。

## 常見問題

**填了素材卻沒反應，先照下表自己檢查。檢查完還是不行，再找工程師。**

| 狀況 | 先檢查 |
| --- | --- |
| 換了動畫沒變化 | 動作標題括號裡的動畫名有沒有變；是否在按下播放後才改（停止就會消失）；改的是不是正確的武器手冊 |
| 沒有聲音 | 清單裡有沒有放「音效資料」；那個音效資料裡有沒有拖音檔；時間點是不是太晚，動作已經被打斷；該武器的手冊是不是玩的那把 |
| 特效沒出現 | Prefab 是否已拖入；Lifetime 是否太短；特效本身在場景中單獨放下去能不能看到 |
| 特效位置跑到腳底 | Bone Name 可能拼錯了。找不到骨骼時會自動退回角色腳底。請工程師確認骨骼名字 |
| 標題顯示「無動畫」 | 這個動作目前沒有動畫連結，請找工程師建立 |
| 換動畫後角色位置或手感怪怪的 | 新動畫的位移與長度影響很大，請找工程師協助調整 |

**這些情況直接找工程師：**

- 要新增一種武器或一個新動作
- 要把「無動畫」的動作補上動畫
- 要改按鍵、傷害、移動速度這類的設定
- Unity 的 Console 視窗出現紅色錯誤訊息
- 資料檔的標題變成「Missing」或整頁空白
